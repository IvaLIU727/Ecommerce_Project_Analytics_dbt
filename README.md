# E-Commerce Analytics Project

An end-to-end analytics pipeline built with dbt Core, DuckDB, and Evidence.dev
using the Brazilian E-Commerce (Olist) public dataset.

## Tools Used
- **dbt Core** — data transformations and testing
- **DuckDB** — local data warehouse
- **Evidence.dev** — dashboard and visualisation
- **GitHub** — version control and portfolio

## Project Structure
- `staging/` — raw data cleaning and renaming
- `intermediate/` — business logic and joins
- `marts/` — final reporting tables (fct_orders, dim_customers)
